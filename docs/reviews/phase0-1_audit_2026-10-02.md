## 🐛 Các vấn đề phát hiện (5 mục)

### Vấn đề 1 — FoodImage thiếu reset state khi `src` thay đổi

- **File:** `src/components/shared/FoodImage.tsx`
- **Mức độ:** 🔸 Trung bình — ảnh hưởng gameplay thực tế
- **Mô tả:** Khi `src` thay đổi (chuyển round mới), `isLoading` và `hasError` vẫn giữ giá trị cũ. Nếu round cũ lỗi ảnh (`hasError = true`), round mới vẫn hiện fallback thay vì ảnh mới.
- **Gợi ý sửa:** Thêm `useEffect` reset state khi `src` thay đổi:
  ```typescript
  useEffect(() => {
    setIsLoading(true);
    setHasError(false);
  }, [src]);
  ```

### Vấn đề 2 — Selectors chưa memoize cho array fallback

- **File:** `src/store/selectors.ts`
- **Mức độ:** 🔸 Trung bình — sẽ thành vấn đề khi phòng 50 người
- **Mô tả:** Các pattern `?? []` tạo reference mới mỗi lần selector chạy (ví dụ `selectParticipants`, `selectScoreEvents`, `selectPastResults`). Khi snapshot cập nhật liên tục (50 người nộp bài), các component dùng selectors này sẽ re-render thừa.
- **Gợi ý sửa:** Khai báo constant empty array và dùng `createSelector` cho selectors tính toán:
  ```typescript
  const EMPTY_ARRAY: never[] = [];
  export const selectParticipants = (state: RootState) =>
    state.room.snapshot?.participants ?? EMPTY_ARRAY;
  ```

### Vấn đề 3 — Socket module-scope instantiation (SSR)

- **File:** `src/lib/socket.ts:20`
- **Mức độ:** ⚠️ Thấp — không gây lỗi runtime
- **Mô tả:** `io()` chạy khi module được import, kể cả trên server-side. Plan ban đầu (section 8.1) dùng lazy pattern `if (!socket) { socket = io(...) }`.
- **Gợi ý sửa:** Đổi sang lazy init hoặc thêm guard `typeof window` trước `io()`.

### Vấn đề 4 — sessionSlice field names khác plan

- **File:** `src/store/slices/sessionSlice.ts`
- **Mức độ:** ℹ️ Rất thấp — không ảnh hưởng logic
- **Mô tả:** Plan ghi `currentRoomCode` và `storedParticipant`, code dùng `roomCode` và `participant`. Selectors đã dùng đúng tên code.
- **Gợi ý:** Cập nhật plan cho đồng nhất với code.

### Vấn đề 5 — Thiếu `.env.local.example`

- **Mức độ:** ℹ️ Thấp — developer experience
- **Mô tả:** Plan yêu cầu tạo `.env.local` nhưng không có file mẫu trong repo. `config.ts` có fallback nên không lỗi.
- **Gợi ý:** Thêm `.env.local.example` vào repo.
